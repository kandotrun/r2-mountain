S3 接続は、実装前の独立した確認として rclone 1.75.2 を使った。
認証情報は専用入力から渡し、プロセス内で解決したアクセスキー ID とシークレットを子プロセスの環境へ渡した。
Cloudflare のアカウント用トークン検証 API で有効性を確認した後、取得したトークン ID を S3 のアクセスキー ID として使用した。
認証情報、アカウント ID、オブジェクト名、一覧の本文は、この文書や Git に保存していない。

最初の接続では、アカウント ID をアクセスキー ID として誤って解釈し、401になった。
アカウント ID とアクセスキー ID を区別し、検証 API から取得した正しい ID を使うと接続に成功した。
このため、アプリの設定画面と接続エラーでは両者を明確に区別する。

確認できた開発環境は Swift 6.4、Xcode 27.1、XcodeGen 2.46.0、just 1.59.0、macOS 27.2（arm64）である。
この時点の文書コミットは `380a01d5db6fdc4c1d4e29dd65a2f08df38660bf` である。

## 2026-11-04の UI 刷新の検証

メインウィンドウ、メニューバー、設定画面を作り直し、macOS 27.2 で操作して確認した。
ドラッグ操作は補助プロセスから合成し、Debug ビルドだけの `--ui-test-floating` で窓を最前面にして他のアプリへ誤ってドロップしないようにした。

| 対象 | 結果 |
| --- | --- |
| `just test` | 101件成功（フォルダ閲覧、フォルダ作成、履歴、最近の保存先、完了済みの消去、転送表示、並び順、キーの正規化を含む） |
| `just lint` / `just build-signed` | 成功、警告なし |
| 新規フォルダ | ツールバーから作成し、R2 にフォルダのマーカーができ、作成したフォルダが開くことを確認 |
| 空のフォルダへのドロップ | 表示中のフォルダへ転送 |
| フォルダ行へのドロップ | 行だけが強調表示され、そのフォルダへ転送 |
| ファイル行・余白へのドロップ | 一覧全体が強調表示され、表示中のフォルダへ転送 |
| 同名ファイル | `行ドロップ確認 2.bin` として転送され、上書きされない |
| 2 GiB の転送 | 進捗、速度、残り時間を表示し、R2 上のサイズが 2,147,483,648 バイトで一致 |
| メニューバー | 保存先メニュー（上の階層、この中のフォルダ、最近の保存先、新規フォルダ）が動作 |
| 表記 | アプリの開発言語を日本語にし、バイト数と日時がシステムの暦設定に沿って日本語で表示 |
| キーボード | 一覧で Return と ⌘↓ でフォルダを開き、⌘↑ で上の階層へ移動。フォルダ移動後もフォーカスが一覧に残る |
| 並び順 | 列見出しで選んだ並び順が、別のフォルダへ移動しても保たれる |

検証で作ったオブジェクトとフォルダのマーカーは、作成したキーだけを指定して削除した。

独立レビュー（正しさ、macOS らしさとアクセシビリティ、R2 の意味論）で確認された指摘を修正した。
主な修正は、NFD で保存されたフォルダへのアップロードでフォルダのバイト列を保つこと、閲覧と転送で接続を分けること、メニューバーのパネルではファイル選択を主な操作にすること、失敗時にメニューバーのアイコンを変えることである。
メニューバーのパネルは、Finder でドラッグを始めると閉じるため、ドロップはウィンドウで行う。
